# Visual Art Direction Reference

The supplied reference images show a stylized top-down/isometric 3D game with cohesive painted/low-poly assets.

Use them as the visual target:

1. Forest:
   - Dense conifer perimeter.
   - Brown dirt paths.
   - Rocks, logs, grass, stream.
   - Green dominant palette.
   - Soft warm daylight.

2. Desert:
   - Sandstone canyon walls.
   - Sandy ground.
   - Sparse dry vegetation.
   - Warm beige/orange palette.
   - Strong but soft-readable sunlight.

3. Ice:
   - Snow-covered conifers.
   - Frozen blue ground.
   - Ice cliffs/crystals.
   - Blue-white palette.
   - Cool atmospheric lighting.

4. Dungeon:
   - Dark stone blocks.
   - Torches.
   - Green poison pools.
   - Purple magical mushrooms/crystals.
   - Strong warm/cool contrast.

5. Sci-fi:
   - Metallic rooms.
   - Cyan floor/wall lights.
   - Red hazard lights.
   - Dark blue-gray environment.
   - Controlled emissive glow.

The important visual rule is consistency: do not combine unrelated realistic, anime, pixel-art, and cartoon asset styles in the same scene.
