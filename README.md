# Naruto — Hành trình Ngũ Đại Nhẫn Thôn

Unity 2021.3.13f1, Built-in Render Pipeline.

Mở Assets/3D.unity và nhấn Play. WASD di chuyển; chuột nhìn/ngắm; V chuyển góc nhìn; Tab thả/khóa chuột; Q/R/F sử dụng nhẫn thuật.

- Assets/Scripts/Lumi: gameplay, camera, UI và kỹ năng.
- Assets/Resources: model Naruto, vật liệu, font, nhạc và ảnh làng hiện dùng.
- Assets/Art/NarutoStarter: FBX nguồn của nhân vật.
- ArtSource/NarutoStarter: file Blender và script dựng model.
- ArtSource/Tools: môi trường Blender dùng để dựng lại model.
- Image: ảnh mẫu Naruto và vĩ thú của người dùng.
- QA: công cụ kiểm tra và tạo tài nguyên.

Library, Temp và UserSettings là dữ liệu Unity tự sinh; không phân phối cùng bản build.
